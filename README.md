# Interactive Quiz Application

A responsive browser-based quiz application developed for **Lecture 10** coursework featuring timed questions, immediate feedback, and score tracking.

## Features
- **Dynamic DOM Rendering**: Questions and options dynamically generated using JavaScript.
- **Instant Evaluation**: Immediate visual feedback for correct and incorrect answers.
- **Live Score Counter**: Tracks user performance across all quiz questions.
- **Clean Responsive Layout**: Styled with responsive modern CSS for desktop and mobile viewports.

---

## Technologies Used
- **HTML5**: Semantic document layout.
- **CSS3**: Modern cards, animations, and color coding.
- **JavaScript (ES6+)**: Event listeners, array traversal, and dynamic DOM updates.
